# CAU Buddy (가칭)

중앙대학교 학생이 **관심사가 같은 외국인 친구**, **같이 공부할 친구**를 찾는 앱입니다.
카카오톡 오픈채팅처럼 카테고리별 채팅방을 만들고 참여할 수 있고, 학생증 인증을 거친 학생만 가입할 수 있습니다.

> 현재 Phase 0(프로젝트 뼈대) 진행 중입니다. 자세한 계획은 [docs/ROADMAP.md](docs/ROADMAP.md)를 참고하세요.

## 저장소 구조

```
cau-buddy/
├── android/   # Android 앱 (Kotlin, Jetpack Compose)
├── server/    # API + 채팅 서버 (Kotlin, Spring Boot)
├── infra/     # 로컬/운영 인프라 (Docker Compose 등)
└── docs/      # 로드맵, 설계 문서, 가이드
```
