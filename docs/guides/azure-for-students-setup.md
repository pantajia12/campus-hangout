# Azure for Students 가입과 무료 자원

운영 서버는 **Microsoft Azure for Students**에 올립니다.
학교 메일 인증만으로 가입되고 **신용카드가 필요 없어서** Oracle Cloud 대신 선택했습니다.

> 2026-11 기준으로 정리한 내용입니다. 혜택은 바뀔 수 있으니 가입 전에 [Azure for Students 공식 페이지](https://azure.microsoft.com/free/students/)를 한 번 확인하세요.

## 받는 것

| 항목 | 내용 |
|---|---|
| 크레딧 | US$100, 12개월 동안 사용. 재학 중이면 매년 갱신해서 다시 받을 수 있음 |
| 12개월 무료 서비스 | Linux VM B1s 월 750시간 (1 vCPU / 1GB 메모리) |
| | Azure Database for PostgreSQL Flexible Server B1MS 월 750시간 + 저장소 32GB |
| | Blob Storage 5GB |
| 카드 | 필요 없음. 크레딧을 다 쓰면 요금이 청구되지 않고 구독이 멈춤 |

월 750시간이면 한 대를 한 달 내내(최대 744시간) 켜 둘 수 있습니다.
학생 구독은 교육·비상업 목적, 소프트웨어 개발과 시연 용도로 쓸 수 있으니 수업 프로젝트에 맞습니다.

## 우리 프로젝트 배치

| 자원 | 용도 |
|---|---|
| VM B1s 1대 (Ubuntu) | Nginx + 서버(Spring Boot) + Redis를 Docker Compose로 실행 |
| PostgreSQL Flexible Server B1MS | 주 데이터베이스 (관리형이라 자동 백업 포함) |
| Blob Storage | 프로필·채팅 이미지(공개 컨테이너), 학생증 이미지(비공개 컨테이너) |

VM 메모리가 1GB라서 DB는 VM 밖의 관리형 PostgreSQL로 뺐습니다. 서버는 JVM 힙을 384MB 정도로 제한하고, VM에 스왑 2GB를 잡아서 돌립니다.

## 준비물

- **중앙대 학교 메일(@cau.ac.kr)** 을 받을 수 있는 상태
- 휴대폰 (문자 인증)
- Microsoft 계정 (없으면 가입 중에 만들 수 있음)

## 가입 순서

1. **신청 페이지 열기**
   [azure.microsoft.com/free/students](https://azure.microsoft.com/free/students/)에서 "Start free"(무료로 시작)를 누릅니다.

2. **Microsoft 계정으로 로그인**
   개인 Microsoft 계정이나 학교 Microsoft 계정 중 하나로 로그인합니다. 학교 계정이 있으면 그걸 쓰는 편이 인증이 수월합니다.

3. **휴대폰 인증**
   국가를 대한민국으로 고르고 번호를 입력합니다. `010-1234-5678`이면 맨 앞 0을 빼고 `1012345678`로 입력합니다.

4. **학업 확인 (학교 메일)**
   학교 메일 주소를 입력하면 인증 메일이 옵니다. 학교 메일함에서 링크를 누릅니다. 안 보이면 스팸함도 확인하세요.

5. **프로필 입력 후 등록**
   이름, 학교, 국가를 입력하고 등록을 누르면 끝입니다.
   [portal.azure.com](https://portal.azure.com)에 들어가서 왼쪽 메뉴 또는 검색창에서 **Education**을 열면 남은 크레딧을 확인할 수 있습니다.

## 가입이 안 될 때

| 증상 | 해결 |
|---|---|
| 학교 메일 인증 중 "High demand" 메시지 | 일시적인 문제입니다. 시간을 두고 다른 네트워크나 브라우저로 다시 시도 |
| 학교 메일 도메인을 인식하지 못함 | 화면에 나오는 수동 인증(재학 증빙 업로드)을 진행 |
| 인증 메일이 안 옴 | 스팸함 확인, 학교 메일 용량이 꽉 차 있지 않은지 확인 |

그래도 안 되면 알려 주세요. 아래 [대안](#대안-render--neon)으로 진행할 수 있습니다.

## 가입 직후 할 일

1. **예산 알림 걸기**
   포털에서 Cost Management → Budgets로 들어가 US$30, US$60, US$90 알림을 만듭니다. 크레딧을 다 쓰면 구독이 멈춰서 서비스가 내려가니, 미리 알 수 있게 해 둡니다.

2. **무료 크기로만 만들기**
   VM은 **B1s**, PostgreSQL은 **Burstable B1MS**를 골라야 무료 한도 안입니다. 다른 크기를 고르면 크레딧이 빠르게 줄어듭니다. 리소스를 만들 때 화면에 나오는 예상 요금을 꼭 확인하세요.

3. **매년 갱신 날짜 기억하기**
   12개월이 지나면 재학생 갱신을 해야 다시 $100를 받습니다.

## 대안: Render + Neon

Azure 인증이 끝내 안 되면 쓰는 방법입니다. **GitHub 계정으로 로그인만 하면 끝**이라 가입은 가장 쉽고, 둘 다 카드가 필요 없습니다.

| 서비스 | 용도 | 무료 조건 |
|---|---|---|
| Render (Free web service) | 서버 | 512MB 메모리, 15분 동안 요청이 없으면 잠들고 다시 깨는 데 약 1분 |
| Neon (Free) | PostgreSQL | 프로젝트당 0.5GB, 월 100 CU-시간, 5분 쉬면 일시 정지 (기한 없음) |

단점: 서버가 잠들면 첫 요청이 1분가량 느리고, 실시간 채팅 연결이 끊길 수 있습니다. Render의 무료 PostgreSQL은 30일 뒤 만료되므로 DB는 Neon을 씁니다.

## 검토했지만 고르지 않은 곳

| 서비스 | 제외한 이유 |
|---|---|
| Oracle Cloud | 카드 필요, 한국 카드로 가입 실패 사례 많음, 2026년에 무료 한도 절반으로 축소 |
| Cloudtype | 무료 플랜도 카드 등록 필요, 매일 1회 자동 중지, 무료 플랜의 웹소켓 타임아웃 1분 |
| Koyeb | 2026년부터 무료 플랜에도 카드 필요 |
| Fly.io | 신규 계정 무료 플랜 없음 |
| Railway | 체험 후 월 $1 크레딧뿐이라 상시 운영 불가 |
